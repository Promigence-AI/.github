# Promigence

Production-grade sandboxes for AI agents. Ready in milliseconds, fast at scale, billed by the second.

Coding agents, CI jobs, evals and RL rollouts each get their own isolated sandbox that opens on your project, already set
up. You see the most a run can cost before it starts.

- Website: [promigence.ai](https://www.promigence.ai)
- Docs: [promigence.ai/docs](https://www.promigence.ai/docs)
- Guides: [promigence.ai/docs/guides](https://www.promigence.ai/docs/guides)

## Install

```bash
npm i -g promigence          # the CLI
npm i @promigence/sdk        # TypeScript SDK
pip install promigence       # Python SDK
```

Framework adapters are on npm and PyPI, among them Harbor, Inspect, Google ADK, Claude Managed Agents, the Vercel AI SDK
and the Claude Agent SDK.
